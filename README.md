**Device_Windows**

**What does the scrips do?**
- Installs common apps with winget using a PowerShell script or two JSON app lists.
- Asks simple questions: gaming setup, development tools, 1Password, SteelSeries, and Dark Mode.
- Detects your GPU and installs AMD Adrenalin or NVIDIA GeForce Experience.
- If gaming = yes, installs Steam, Epic, EA Desktop, Ubisoft Connect, and Battle.net.
- Downloads the Rockstar Games Launcher installer.
